# Security policy

Only the current 0.2.3 source release is in scope for this community project. No response SLA is promised. This is not an official DeepSeek product.

Do not publish credentials, exploit payloads against live systems, internal addresses, full prompts or raw sensitive logs in a public Issue. Use the repository's **Report a vulnerability / private vulnerability reporting** if its maintainer has enabled it. If unavailable, open only a minimal public request for a private reporting channel, without exploit details; wait for the maintainer to provide one. No personal email address is published here.

Include affected version, a synthetic offline reproduction, impact and suggested remediation through the private channel. Do not test systems without permission. See docs/security.md for the trust model and known limitations. Maintainers must enable private reporting and review release ownership before public launch.
